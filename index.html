TaxScope UK

UK tax calculators for PAYE, NI, limited companies, IR35, dividends and more.

Live · Web + AndroidPrivate
  • Implements HMRC's PAYE Tax Table Routines spec v24.0 in exact Decimal arithmetic. Covers tax-code parsing (S/C prefixes, K codes, W1/M1), cumulative and non-cumulative bases, and the statutory rounding rules.
  • Checked against HMRC reference vectors for each tax year.
  • A salary/dividend optimiser that tests only the kink points of the piecewise-linear take-home curve, so it gives an exact answer instead of a grid-search estimate.
  • The Android app runs a line-by-line TypeScript port of the engine offline. Golden fixtures exported from the Python engine keep the two in step.

AuthMCP Gateway

An authenticating proxy that merges several MCP servers into one endpoint.

Open source · PyPI
  • Proxies the full MCP protocol (tools, resources, prompts, completions) with per-backend namespacing and Streamable-HTTP session tracking.
  • OAuth 2.1 for MCP clients: PKCE, Dynamic Client Registration, and Client ID Metadata Documents with SSRF hardening. JWT rotation and a blacklist.
  • Recovers stale sessions under concurrency with a per-server lock and a double check. Decides retries from tool annotations and adds idempotency keys, so a "send message" call is never sent twice.
  • Backend secrets are encrypted at rest. Includes CSRF protection, rate limiting, a security event log and a built-in MCP security auditor.

USBImageClone

Captures a bootable USB drive and writes it to many drives at once, in the spirit of Rufus or Etcher.

Private

MultiUSBSync

Pushes a folder onto many USB drives at once. A general-purpose tool that works with any content.

Private
  • Reads each source file once and writes it to every drive at the same time.
  • Each copy goes to a temporary part file and is renamed only when complete. A pulled drive leaves no half-written files and doesn't stop the others.
  • Copies only what changed, by hash. Large files bypass the Windows file cache, so the PC stays responsive during multi-gigabyte copies.
  • Notices when a drive slows down mid-copy, refuses to scan a whole 2 TB disk by accident, and replaces read-only files while keeping their attributes.

How I work

Habits that show up across the code

These are patterns I saw again and again when reviewing these repositories, not slogans.

Check against a reference

Tax engines are tested against HMRC vectors. The mobile port is checked against golden fixtures exported from the server. The new build pipeline is compared byte for byte with the system it replaced.

Measure before choosing

Proofing models, chunking and the Word export path were each chosen by benchmark, and the results are written up. Keystroke latency is measured, not guessed.

Safe by default around hardware and money

Every BIOS setting is read back after writing. Every disk write passes a preflight check first. Money is always Decimal. Secrets are encrypted at rest, and tool calls carry idempotency keys.

Ship the whole thing

Installers, release scripts with checksums, migrations, user guides for non-developers in PDF and HTML, and design-decision records in English and Russian.

Open-source contribution: my fix for a race condition in auto-checking was merged into the LanguageTool plugin for Obsidian.
